# My agent: FitCoach AI

One-liner: A conversational agent that helps fitness enthusiasts plan workouts, log activities, and track performance with a catalog of exercise routines and training plans.

Tool coverage:
- Memory: User fitness goals, physical limitations, personal records (PRs), and workout history across sessions.
- Tools: Exercise library lookup by muscle group/equipment, workout logging, training metrics calculation.
- Catalog/UI: Exercise routines and weekly workout plans rendered as rich A2UI cards and structured tables.
- Image gen: Personalized workout motivation cards and exercise posture visual guide images.
- Sandbox: Target heart rate zone calculation, caloric burn estimation, and macro target breakdown.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: Code sandbox for training calculations, Cloud Trace for latency tracking.
